# midgard-launcher-dist

Arquivos de distribuicao do **Midgard Launcher**, servidos via GitHub Pages.

- `distribution.json` — indice lido pelo launcher a cada abertura
- `servers/` — mods de cada perfil (Fraco / Medio / Forte)
- `repo/` — Fabric loader, bibliotecas e version manifest

Gerado pelo [Nebula](https://github.com/dscalzi/Nebula). **Nao editar a mao**: alterar os
arquivos de origem e rodar `npm run faststart -- g distro` no Nebula.

Os mods redistribuidos aqui sao open-source e mantem suas licencas originais
(Sodium, Lithium e Iris: LGPL-3.0; FerriteCore: LGPL-3.0; Fabric API: Apache-2.0).
